Development Page

開發 Roadmap

先確保遊戲能完整「出發 → 探索 → 撤離」，再逐步加入 AI NPC 與多 Agent 能力。

本頁內容 Development Principle Phase 1Phase 2 Phase 3Success Criteria Related Content
01 Development Principle

先做可玩的版本

期末專案不一次追求完整大型遊戲，而是先完成一個可正確操作的核心版本。AI 功能也採漸進式加入，避免因模型延遲或 API 問題讓基本遊戲無法運作。

02 Phase 1

MVP：完整撤離循環

可移動的 2D 地圖

玩家移動、地圖邊界與基本碰撞。

搜刮、背包與戰鬥

建立基本物品、容量限制、敵人與 HP。

任務與撤離

完成任務後前往撤離點，成功後保留本局戰利品。

AI 動態任務 / 事件

讓 LLM 根據 Game State 產生有限且可驗證的內容。

03 Phase 2

AI NPC 與 RAG

建立世界觀、地圖與 NPC 知識庫，讓角色回答玩家問題時先檢索資料，再依照角色設定生成回應。

04 Phase 3

進階 Agent 系統

Reflection

檢查 AI 任務是否能完成、是否超出地圖物資或與 Game State 衝突。

Planning

將較複雜的任務拆成數個可追蹤目標。

Player Modeling

記錄玩家偏好與風險習慣，作為後續事件生成條件。

基地擴充

增加 NPC、倉庫、裝備與升級系統。

05 Success Criteria

期末預期成果

玩家能完成「基地準備 → 接受任務 → 進入地圖 → 探索 / 搜刮 / 戰鬥 → AI 事件 → 撤離 → 結算 → 返回基地」的完整流程。
