AI 技術架構

將 Prompt Engineering、Tool Use、RAG、Planning、Reflection 與 Agent Workflow 分配到真正需要的遊戲功能。

01 Overview

架構原則

AI 不負責所有事情。即時性高且規則明確的功能由一般程式處理；需要理解文字、生成內容或做高階判斷的部分才交給 LLM。

02 System Layers

三層架構

Game Layer

移動、碰撞、戰鬥、背包、HP、撤離與數值計算。

AI Director Layer

任務、事件、情境與高階決策。

Knowledge Layer

世界觀、地圖、NPC、物品設定與向量檢索。

03 AI Techniques

課堂技術如何使用

技術遊戲用途角色
Prompt Engineering限制世界觀、NPC 個性與輸出格式。基礎規則
Tool Use查詢玩家狀態、背包、地圖與任務資料，再執行更新。核心
RAGNPC 先檢索世界觀與地圖知識再回答。第二階段
Planning將複合任務拆成可追蹤的多階段目標。進階
Reflection檢查任務能否完成、數量是否合理、是否與 Game State 矛盾。進階
Agent Workflow分離 AI Director、Quest Agent 與 NPC Agent 的責任。整合

06 System Boundary

不交給 AI 的工作

角色移動、碰撞、HP 扣除、掉落機率與背包容量等規則應由遊戲程式控制。這可以減少 API 延遲、降低成本，也避免 LLM 產生不一致的遊戲數值。
